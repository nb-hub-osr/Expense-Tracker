# 💰 Expense Tracker

A beginner-friendly Python command-line application for managing personal expenses.

## 📌 Features

- Add new expenses
- View all expenses
- Calculate total spending
- Delete expenses
- Search expenses by category
- Category-wise spending summary
- Monthly spending summary
- Edit existing expenses
- Automatic date for each expense
- Save data using JSON
- Input validation and error handling

## 🛠️ Technologies Used

- Python
- JSON
- `datetime` module

## ▶️ How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python expense_tracker.py
```

5. Follow the menu displayed on the screen.

## 📂 Project Files

- `expense_tracker.py` — main Python program
- `expenses.json` — stores expense data
- `README.md` — project documentation
